# 握拳出击 · Fist Up

一个用双手握拳的体感拳击小游戏。敌人从左右两侧不断逼近，对应方向握拳挥出即可反击；被贴身击中 3 次本局结束，配一段电子风背景音乐。

---

## 一、怎么启动

> ⚠️ **不要直接双击 `index.html`**。摄像头在 `file://` 下会被浏览器拦截，必须通过本地服务访问。

### 方式一（推荐）：双击「启动游戏.bat」

1. 在项目文件夹里找到 **`启动游戏.bat`**，双击它。
2. 会弹出命令行窗口，自动启动本地服务并用默认浏览器打开页面（需已安装 Python 3 并加入 PATH）。
3. 页面加载后，点击中间的 **「开 始 游 戏」** 按钮 → 浏览器弹窗请求摄像头时点 **「允许」**。
4. **用完关闭那个命令行窗口即可停止服务。**

> 双击后窗口一闪就消失：说明没检测到 Python。先安装 Python 3，安装时勾选「Add python.exe to PATH」。

### 方式二（备选）：命令行

打开 PowerShell，执行：

```powershell
cd "D:\Users\lenovo\Documents\Trae-CN\default\boxing"
python _server.py
```

然后浏览器打开 **http://localhost:8010**。窗口别关，关了服务就停了。

如果提示端口被占用，打开 `_server.py` 把 `PORT = 8010` 改成别的数字（如 8011），再访问对应端口。

### 方式三：线上直接玩

浏览器打开 **https://qmymr.github.io/boxing/** ，允许摄像头后点「开 始 游 戏」即可。

> `*.github.io` 在国内网络可能打不开或很慢，开了代理再试；打不开就用方式一或方式二。

## 二、怎么玩

| 操作 | 效果 |
| --- | --- |
| **左手握拳挥出** | 击倒左边来的敌人 |
| **右手握拳挥出** | 击倒右边来的敌人 |
| **敌人贴身** | 扣 1 颗心（共 3 颗） |
| **3 颗心耗尽** | 本局结束并结算 KO 得分 |
| 顶部 **❚❚** 按钮 | 暂停 / 继续 |
| 右下角摄像头小窗 | 摄像头回看；下方「左 / 右」检测到对应手时亮起 |

小提示：左右由屏幕镜像判断（你面向屏幕抬起的手，对应你看到的那一侧）；挥拳要握实，蜷起至少 3 根手指才算握拳。

### 键盘降级（摄像头用不了时）

| 按键 | 作用 |
| --- | --- |
| `A` / `←` | 打左边来的敌人 |
| `D` / `→` | 打右边来的敌人 |

## 三、按键一览

| 按键 | 功能 |
| --- | --- |
| `A` / `←` | 左侧出拳 |
| `D` / `→` | 右侧出拳 |
| `Esc` | 暂停 / 继续；设置面板中则返回上一级 |
| `空格` / `Enter` | 菜单界面开始游戏；暂停时继续 |

暂停面板里可随时「继续」「设置」（调音量、切中英文）或「退出本局」回主菜单。

## 四、常见问题

**Q：点击「开始游戏」后没有弹出摄像头授权窗口？**
A：检查浏览器地址栏左侧的摄像头图标是否被划掉，点它改成「允许」；或换 Chrome / Edge 浏览器。

**Q：摄像头小窗里有人，但挥拳没反应？**
A：把手完整放进画面，光线别太暗，手离摄像头 30–60 厘米；握拳要完全蜷起再挥出，多试几次。

**Q：没有声音？**
A：必须先点「开 始 游 戏」（浏览器要求用户操作后才能播放声音）；音量可在设置里调。

**Q：双击 `启动游戏.bat` 没反应 / 一闪而过？**
A：未安装 Python 3 或未加入 PATH，安装时记得勾选「Add python.exe to PATH」。

**Q：线上地址打不开？**
A：`github.io` 域名受网络影响较大，改用本地的 `启动游戏.bat`，或开代理后再访问。

## 五、目录说明

```
boxing/
├── index.html / style.css / game.js   网页本体（运行必需）
├── vendor/                            MediaPipe 手势识别库与模型（运行必需）
│   ├── mediapipe/                     vision_bundle.js/.mjs + wasm
│   └── models/                        hand_landmarker.task
├── _server.py                         本地服务器（修复 .mjs / .wasm 的 MIME 类型）
├── 启动游戏.bat                        双击启动本地服务（推荐）
└── README.md
```

平时只需要管根目录的这几个文件和 `启动游戏.bat`，`vendor/` 不要改动。
